# Hybrid retrieval and training FAQ ingestion

The approved 2026-10-17 instruction supersedes the historical ordering in T4 without modifying that task file. Query order is authorization, as-of applicability, injection exclusion, latest applicable family/product/region version, hybrid cosine/lexical scoring, then the configured threshold. Excluded document text never enters query-time embeddings or generation. Only the query is embedded at request time.

At trusted ingestion, validity intervals and injection scans run before document embedding. Historical/future documents with valid metadata may have stored vectors; applicability is checked again before query similarity. Cache keys include document identity, version, scope, dates and content; model name is stored separately. Changed content produces a new vector. A model change requires explicit `PolicyRetrievalEngine.reindex()`; absent/new-model vectors and provider failures use lexical retrieval. Snapshot contents stay immutable; vector cache rows are content-addressed and shared with pinned snapshot views. T1 candidate ingestion and golden evaluation use this same cache and pipeline, including added paraphrase golden questions.

Flagged instruction spans are replaced by a neutralization marker while surrounding text remains for inspection. The flagged parent remains available for audit. Only independent safe sentences can enter an unflagged retrieval/embedding view; neutralized instructions and pure instruction documents remain excluded. T1 file ingestion continues to quarantine injection-flagged files with their original evidence, as T1 requires.

The original `dataset/dataset.csv` is decoded as UTF-8 or its original Windows-1252 encoding, without changing its bytes. Each FAQ becomes a public version-1 bootcamp document with its actual question as section, actual response as content and a distinct family. New empty stores with a configured provider ingest these documents before initializing ACTIVE; unconfigured offline stores remain empty and existing approved snapshots are not silently modified. Troubleshooting fixtures live in `data/troubleshooting/`.

The frozen 72-case holdout was committed before retrieval changes. Twenty cases expect a supported answer; 52 expect refusal (including 12 lookalikes). `scripts/evaluate_t4.py --live` records answer rate, correct cited-answer rate, false-answer rate and provider errors. Scripted-vector tests establish filtering/citation/cache contracts only; they do not establish semantic model accuracy. No threshold or synonym rules are fitted to this corpus.

Provider API contract: [Google embedding reference](https://ai.google.dev/api/embeddings). The provider adapter uses batchEmbedContents with document/query task types. Actual model availability is separately measured, not inferred from documentation.
