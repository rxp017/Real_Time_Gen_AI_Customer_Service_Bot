# Current verified limits - 2026-10-17

- Hybrid retrieval exists, but the frozen actual-provider evaluation answered only 3/20 supported questions with correct citations. Its 0/52 false answers is small-set evidence, not universal safety. Extractive verification refuses unsupported paraphrases and may reduce recall.
- Provider-assisted sentiment scored 22/48 on the newly committed set, versus 17/48 for unchanged patterns. Only six model classifications were accepted. These are authored diagnostic examples, not a blinded production benchmark; confidence is not calibrated probability. High-risk rules remain separate but miss unrepresented wording.
- Live translation hit HTTP 429, so successful live translation remains unverified. Source/curated fallback works and tested entity bytes survive. Placeholder/numeric/citation validation cannot independently prove translation meaning. Names outside configured patterns can still be missed.
- The original FAQ CSV is imported with metadata for a configured new empty store. The legacy Streamlit/LangChain/GooglePalm chain remains preserved but unverified; the supported API uses the shared engine. Existing approved snapshots are not silently seeded or overwritten.
- OCR recognizes the tested synthetic invoices and installed language packs, not arbitrary layouts, handwriting or document authenticity. PNG/JPEG and a conservative PDF subset are accepted. Injection detection is pattern-based; actual OCR instruction wording outside those patterns can still pass extraction. Structural data isolation does not prove universal malicious-file safety.
- Jobs, upload result notifications, escalation queues and ticket/SLA events are local SQLite records. No external helpdesk/email/paging delivery is configured. The agent roster is empty until real agents are supplied. Customers must supply mandatory ticket fields; the UI does not invent them.
- SQLite, in-process scheduling, rate budgets and upload recovery require one application instance/worker and writable storage. Distributed coordination, encrypted storage and production process containment are unverified. Retention tests prove unlinking, not forensic erasure.
- Render Free sleeps after inactivity, stopping scheduler/SLA/retention processing while stopped; its filesystem is ephemeral and a restart can lose state. A suitable continuously running service and persistent storage are needed for durable operation. No public live deployment was completed.
- Only gemini-2.5-flash has successful documented generation among the candidate generation models. The example fallback list is empty. The API key does not establish account billing tier; model listing does not establish quota. Failed provider calls return genuine failure or the documented domain fallback.
- The supported runtime is Python 3.11; the Windows bootstrap uses official portable 3.11.9. The full suite preserves the Starlette TestClient/httpx deprecation warning. Hosted CI verifies fresh Ubuntu/Windows checkouts and Docker build/OCR checks, not production reliability.
